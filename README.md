# Study Room Booking

Study Room Booking là ứng dụng hỗ trợ tìm kiếm và đặt chỗ phòng học nhanh chóng, tiện lợi. Dự án được phát triển trên nền tảng React Native và Expo, hỗ trợ chạy đa nền tảng trên cả thiết bị di động lẫn trình duyệt web.

## Xem nhanh

- **Live Demo (Vercel):** [Cập nhật link Vercel tại đây](https://my-study-room-app-eight.vercel.app/)
- **GitHub:** [Cập nhật link GitHub tại đây](https://github.com/thaoct04/My-study-room-app)

## Cài đặt và chạy dự án

### Yêu cầu hệ thống
- Đã cài đặt Node.js và npm trên máy tính
- Ứng dụng Expo Go trên điện thoại (nếu chạy trực tiếp trên thiết bị di động)

### Các bước thực hiện
1. Tải mã nguồn về máy (Clone repository):
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   cd My-study-room-app
   ```
2. Cài đặt các thư viện cần thiết:
   ```bash
   npm install
   ```
3. Khởi chạy dự án với Expo:
   ```bash
   npx expo start
   ```

### Chạy trên điện thoại bằng Expo Go
Mở ứng dụng Expo Go trên điện thoại và quét mã QR hiển thị trên terminal hoặc giao diện Expo Dev Tools. Đảm bảo điện thoại và máy tính đang sử dụng chung một mạng Wi-Fi để kết nối.

### Chạy trên trình duyệt Web
Khi Expo đã khởi động, nhấn phím `w` trong terminal để mở ứng dụng trên trình duyệt, hoặc khởi chạy trực tiếp bằng lệnh:
```bash
npx expo start --web
```
