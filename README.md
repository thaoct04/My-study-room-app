# Study Room Booking

Study Room Booking là ứng dụng đặt phòng học, giúp người dùng tìm và đặt chỗ học thuận tiện. Ứng dụng được xây dựng bằng React Native và Expo, có thể chạy trên thiết bị di động hoặc trình duyệt web.

## Xem nhanh

- **Live Demo (Vercel):** [Cập nhật link Vercel tại đây](https://my-study-room-app-eight.vercel.app/)
- **GitHub:** [Cập nhật link GitHub tại đây](https://github.com/thaoct04/My-study-room-app)

## Cài đặt và chạy dự án

### Yêu cầu

- Node.js và npm
- Expo Go trên điện thoại nếu muốn chạy ứng dụng trên thiết bị

### Các bước

1. Clone repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   cd My-study-room-app
   ```

2. Cài đặt các package:

   ```bash
   npm install
   ```

3. Khởi động Expo:

   ```bash
   npx expo start
   ```

### Chạy trên điện thoại bằng Expo Go

Mở Expo Go trên điện thoại, sau đó quét mã QR hiển thị trong terminal hoặc trang Expo Dev Tools. Điện thoại và máy tính cần kết nối cùng mạng để kết nối trực tiếp.

### Chạy bản Web

Khi Expo đang chạy, nhấn `w` trong terminal để mở ứng dụng trên trình duyệt. Hoặc chạy trực tiếp:

```bash
npx expo start --web
```
